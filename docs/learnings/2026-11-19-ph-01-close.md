## What happened

The first console run with Gemini found two defects: the console sent its token to whatever held the port (fixed by a mutual handshake, R-01.F9), and a muted session timed out (fixed by a keep-alive, R-01.F10). The operator did S1 and S2 by hand. An automated Chrome harness with synthetic speech then ran S3 to S7. The maintainer accepted that run as the RT-G01 native-media evidence and closed PH-01 on 2026-11-19.

## What we learned

- A harness can measure stop, barge-in, mute, and restart timing without a person, and it keeps real speech out of a cloud call.
- A run is tied to a commit. Two later commits were not covered, and the record says so instead of widening the claim.
- Tool calls were not visible in the console, so the model's own claim of using a tool is not evidence.

## What to do differently

Show tool use in the console so a run can verify it. Record self-testing when it is used as evidence, even in one line.

## Still unknown

Latency against targets (PH-03), behavior of the two later commits in a recorded live run, and the open boundary findings B3 to B8.
