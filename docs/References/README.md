# Architecture diagram references

This folder contains Lucidchart JSON reference files. They are proposals and
do not authorize runtime access, external actions, provider use, or spending.

| File | Purpose |
| --- | --- |
| [projectdiagram.json](projectdiagram.json) | Original user-authored architecture sketch, preserved unchanged. |
| [personal-agent-architecture.json](personal-agent-architecture.json) | Expanded personal-agent platform and universal task-lifecycle diagram for import into Lucidchart. |

The expanded diagram has two pages:

1. Platform architecture: interfaces, clarification, orchestration, ledger,
   policy, memory, capability workers, scoped tools, external systems, and
   verified responses.
2. Universal task lifecycle: understand, clarify, check feasibility, plan,
   authorize, execute, monitor, verify, respond, and retain only approved data.

The JSON follows the same Lucidchart shape-and-line format as the source
sketch. Import behavior and visual auto-layout must still be verified in the
Lucidchart application. The Markdown proposal at
[personal-agent architecture](../product/personal-agent-architecture.md)
contains a reviewable Mermaid rendering of the same design.
